# 发言统计

「发言统计」会静默记录群成员的发言次数，按日、周、月三个周期分别统计，并支持查看排行榜与清除记录。它不需要任何指令参与统计——只要机器人在群里收到消息，计数就会自动累加。

## 启用条件

| 条件 | 说明 |
| --- | --- |
| `example.fayan.enable` | 发言统计开关，默认 `true`；关闭后既不统计也不响应指令 |
| 仅群聊 | 私聊不统计、也不响应；源码在 `Bot.on('message')` 与指令里都会判断 `e.group` |
| 无需艾特 | 统计是被动进行的，任何群消息（包括指令本身）都会让发送者 +1 |

插件名为「魔族陌:发言统计」，优先级 `priority: 1145`（源码写死）。

## 指令一览

| 指令 | 说明 | 备注 |
| --- | --- | --- |
| `发言榜` | 查看本群发言榜，默认按天统计 | 显示前 `count` 名，附带你自己的排名 |
| `发言榜日榜` | 查看日榜 | 可加数字，如 `发言榜日榜1` 查看往前推一天的日榜 |
| `发言榜月榜` | 查看月榜 | `发言榜月榜1` 查看上个月的月榜 |
| `发言榜周榜` | 查看周榜 | `发言榜周榜1` 查看上一周的周榜 |
| `清除本群发言` | 清空本群当前统计周期内的全部发言记录 | 仅主人；非主人触发时静默不响应 |
| `清除发言` | 清除被艾特成员在本群的发言记录 | 仅主人；**必须艾特**，否则提示未获取到艾特数据 |

::: tip 等价写法
清除本群发言的正则是 `^#?(清空|清除)(本群|群聊)发言(记录|榜)?$`，所以 `清空本群发言`、`清除群聊发言`、`清除本群发言记录`、`清除本群发言榜` 都是同一个功能。

清除发言的正则是 `^#?清除发言(记录|榜)?`，`清除发言记录`、`清除发言榜` 等效。
:::

## 榜单类型与数字参数

榜单分日榜、月榜、周榜三种，数字参数表示**往前推几个周期**，都是通过改变 Redis 键里的日期实现的：

| 榜单 | 日期格式 | `发言榜日榜1` 的含义 |
| --- | --- | --- |
| 日榜（默认） | `YYYY-MM-DD` | 往前推 1 天的日榜 |
| 月榜 | `YYYY-MM` | 往前推 1 个月的月榜 |
| 周榜 | `YYYY-WeekNN` | 往前推 1 周的周榜（以周一为第一天） |

数字可以省略榜单类型直接写，此时按日榜解析，例如 `发言榜 7` 查看 7 天前的日榜。

## 显示样式

| 场景 | 输出 |
| --- | --- |
| QQBot 适配器 + `sendMarkdown: true` | Markdown 卡片：开头用 `<@QQ号>` 提及触发者，标题为 `**本群发言榜<日榜/月榜/周榜>**`，逐条显示 `**No.N 昵称**` 与 `>发言次数：N次`，并带上「数据仅供参考  请以实际发言为准」「日期：<日期>」两行，分区用 `***` 分隔，末尾给出「你的发言」（排名与次数），同时附带「日榜 / 月榜 / 周榜」按钮 |
| 其它情况 | 纯文本榜单：首行 `本群发言榜<类型>`，用 `--------` 作分隔线，同样带「数据仅供参考  请以实际发言为准」「日期：<日期>」两行，逐行显示 `第N名：昵称•N次`，末尾给出「你的排名：第N名 • N 次」 |

- Markdown 分支的按钮由 `segment.button` 生成，一次给出「日榜 / 月榜 / 周榜」三个按钮；点击后等价于发送 `发言榜日榜`、`发言榜月榜`、`发言榜周榜`（按钮依赖 QQBot 的按钮能力，这也是 `sendMarkdown` 被标注为「仅QQBot使用」的原因）。
- 提及里的 QQ 号会先去掉 `self_id:` 前缀（`user_id.replace(self_id + ':', '')`）。
- 该统计周期内一条记录都没有时，Markdown 分支额外输出 `>暂无数据`，纯文本分支输出 `暂无数据`。
- 只有你自己在该统计周期内有发言记录（即存在于对应的 zset 中）时才会显示个人排名块；完全没有记录就没有这一段，个人排名不受「前 N 名」限制。

## 数据存储

发言统计的数据全部放在 Redis 里，键名规则如下：

| Redis 键 | 类型 | 内容 |
| --- | --- | --- |
| `Mozu:msg:<日期>:group:<机器人ID>:<群号>` | 有序集合 zset | 成员 ID → 发言次数，用 `ZINCRBY` 累加 |
| `Mozu:username` | 哈希 hash | 成员 ID → 最近一次发言的昵称 |

- 日榜、周榜、月榜各占一个键，所以一次发言会同时写三个键（源码用 `pipeline` 批量执行）。
- 「清除本群发言」是删除当天的日、周、月三个键，「清除发言」是从这三个键里删掉该成员的记录，因此清除只影响当前周期。
- 键名中的群号会去掉 `self_id:` 前缀（`group_id.replace(self_id + ':', '')`）。
- 榜单最多取 `count` 条（`ZREVRANGE 0, count - 1`），昵称从 `Mozu:username` 批量读取。

::: info Redis 连接
Redis 连接参数由 `config/config/Redis.yaml` 提供（`host`、`port`、`database` 等），本插件不自带 Redis 服务。配置说明见 [配置文件说明](/config/files)。
:::

## 配置项

配置文件是 `config/example/config/fayan.yaml`（仓库自带的模板为 `config/example/default/fayan.yaml`）。

| 配置键 | 锅巴面板标签 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `example.fayan.enable` | 发言统计开关 | 总开关，同时控制统计与指令 | `true` |
| `example.fayan.sendMarkdown` | 使用Markdown发送 | 「是否使用Markdown发送，仅QQBot生效」，非 QQBot 适配器下即使打开也用纯文本 | `true` |
| `example.fayan.count` | 排行榜最多显示数 | 榜单显示条数，面板限制最小为 `1`，用于避免刷屏 | `10` |

## 注意事项

- 统计不区分消息类型，聊天、图片、指令都会 +1。
- 昵称是每次发言时写入的，成员改昵称后榜单会显示最新昵称。
- 清除类指令只有主人可用，其他人发送会被静默忽略（不回复任何内容）。
- 「清除发言」依赖消息里的艾特段（`e.at`），如果艾特没有解析出来，机器人会回复正确格式提示。
