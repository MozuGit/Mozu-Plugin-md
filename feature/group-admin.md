# 群管

「群管」给 **QQBot 适配器**补上禁言与踢人能力。插件名是「魔族陌:官机群管」，源码在 `apps/groupAdmin/`，接口封装在 `model/QQBot/interface.js`。

QQBot 适配器没有 OneBot 的 `set_group_ban` 这类接口，所以这里直接调 QQ 开放平台的 `restrict_chat_setting`（禁言）与 `batch_remove_members`（踢人）。**只在 QQBot 下可用。**

::: warning 默认关闭，而且在面板里找不到
`config/groupAdmin/default/setting.yaml` 的 `enable` 默认 `false`，要手动改 YAML 打开（这一组没有锅巴面板）。没打开时所有群管指令都静默返回。
:::

## 使用前提

| 条件 | 说明 |
| --- | --- |
| 适配器 | 仅 QQBot，其他适配器静默返回 |
| 场景 | 仅群聊 |
| 开关 | `groupAdmin.setting.enable` 必须为 `true` |
| 机器人权限 | 必须是群管理，否则回复「Bot权限不足，需要管理员权限」 |
| 操作者权限 | 群主 / 群管 / 主人，否则回复「该命令仅限群管理员可用」 |

主人可以绕过操作者校验，但仍需要机器人自己是管理。

## 指令

| 指令 | 说明 |
| --- | --- |
| `#禁言 @某人 [数字] [单位]` | 禁言被 @ 的成员，可一次 @ 多人 |
| `#解禁 @某人` | 解除禁言，并显示每人剩余禁言时间 |
| `#踢 @某人` / `#踢黑 @某人` | 移出本群，`#踢黑` 同时加入群黑名单 |
| `#解除全部禁言` | 解除本群所有人的禁言 |

`#禁言`、`#解禁` 后面可以跟其他文字；`#踢` / `#踢黑` 与 `#解除全部禁言` 必须完全一致。所有指令都要带 `#`。

### 禁言时长

```text
#禁言 @张三             → 1 分钟（默认）
#禁言 @张三 10          → 10 分钟
#禁言 @张三 10 秒       → 10 秒
#禁言 @张三 半小时      → 1800 秒
#禁言 @张三 @李四 30 分钟
```

- **数字**由 `tools/translateChinaNum.js` 解析，`10`、`十`、`三十`、`一百二十` 都认；不写按 `1`。
- **单位**不写时按 60 秒算。

| 单位 | 秒 | 单位 | 秒 |
| --- | --- | --- | --- |
| 毫秒 | 0.001 | 时 / 小时 / h | 3600 |
| 秒 / s | 1 | 天 / 日 / d | 86400 |
| 分 / 分钟 / m | 60 | 周 / w | 604800 |
| 月 | 2592000 | 年 / y | 31536000 |

英文单位不区分大小写。

::: tip 两个注意点
1. 单位是从**整条消息**里取第一个命中的词，所以被 @ 的人昵称里带「天」「分」时可能误判。
2. 实际禁言会比填写时长**多约 1 秒**（接口按「当前秒 + 时长 + 1」算到期时间）。
:::

### 目标只认 @

禁言、解禁、踢人都只从 @ 提及里取目标，直接打 QQ 号或 openid 无效。群主与管理员会被自动排除（只保留 `member_role === 'member'`），过滤后为空就提示「未找到…对象」。

禁言与踢人都**每 20 人一批**发送，任一批失败即整体失败。

## 行为变化

这批更新给三处 `muteMembers(...)` 补了 `await`。此前没有等待结果，`ok` 恒为真，**接口失败也会回「禁言成功」**；现在失败时不回复。

## 配置

```yaml [config/groupAdmin/default/setting.yaml]
enable: false    # 群管开关
priority: 100    # 指令优先级，越小越先响应（改后需重启）
```

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 发 `#禁言` 没反应 | `enable` 还是 `false`、不是 QQBot、或在私聊里 |
| 回复「Bot权限不足」 | 机器人不是群管理 |
| 回复「仅限群管理员可用」 | 操作者不是群主 / 群管 / 主人 |
| 操作了但没回执 | 接口失败时不回复，先看日志有没有 `[魔族陌][Interface]` |
| `#解除全部禁言` 没回复 | 群里本来就没有人被禁言 |
| 只踢了一个人 | 多个目标要分别 @，或确认其余人是群主 / 管理员（会被跳过） |
